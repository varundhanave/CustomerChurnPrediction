## Project Description

Customer churn (customers leaving a service) is a major and costly problem for telecom companies. Winning a new customer is far more expensive than keeping an existing one.

This project analyses the **IBM Telco Customer Churn** dataset to:

1. Understand **why** customers churn using Exploratory Data Analysis (EDA)
2. **Predict** which customers are likely to churn using machine learning
3. **Explain** which factors drive churn (permutation feature importance)
4. Convert predictions into **High / Medium / Low risk segments** for a retention team
5. Provide **actionable business recommendations**

## Methodology in Brief

1. **Data cleaning:** converted `TotalCharges` to numeric; the 11 blank values belong to brand-new customers (tenure = 0) so they were set to 0.
2. **EDA:** churn rate by contract, tenure, internet service, payment method, add-on services and charges.
3. **Feature engineering:** `NumAddOnServices` and `AvgChargePerMonth`.
4. **Modelling:** Logistic Regression, Random Forest and Gradient Boosting using an 80/20 stratified split, 5-fold cross-validation and `class_weight="balanced"` for the imbalanced target.
5. **Tuning:** GridSearchCV optimising ROC-AUC.
6. **Evaluation:** accuracy, precision, recall, F1, ROC-AUC, confusion matrix, threshold trade-off.
7. **Explainability and risk scoring:** permutation importance and churn-probability risk segments.

## Key Results

| Model | Accuracy | Recall | F1 | ROC-AUC |
|---|---|---|---|---|
| Logistic Regression | 0.740 | 0.786 | 0.616 | 0.842 |
| Random Forest | 0.761 | 0.778 | 0.633 | 0.844 |
| Gradient Boosting | 0.797 | 0.497 | 0.565 | 0.843 |
| **Gradient Boosting (tuned), final model** | **0.796** | **0.487** | **0.558** | **0.846** |

- Lowering the decision threshold from 0.5 to 0.3 raises churn recall from **48.7% to 77.8%**, which suits a retention campaign.
- Predicted **High-risk** customers actually churned **71.9%** of the time (Medium: 42.9%, Low: 9.7%).

## Key Insights

- **Month-to-month** contracts churn at **42.7%**, versus 2.8% for two-year contracts.
- Customers in their **first 12 months** churn at **47.4%**.
- **Fiber optic** (41.9%) and **electronic check** (45.3%) customers churn the most.
- Customers **without Tech Support or Online Security** churn nearly three times as often as those with them.
- Gender has no meaningful effect on churn.

## Recommendations

1. Incentivise month-to-month customers to move to longer contracts.
2. Create a first-year onboarding and check-in programme.
3. Bundle Tech Support and Online Security for fiber optic customers.
4. Encourage automatic payment methods.
5. Run the model monthly and give the High-risk list to the retention team first.
